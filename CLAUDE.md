## Agent skills

### Issue tracker

Tickets live in the local Tandembike app through MCP at `http://localhost:3000/api/mcp`; use its `Ticket` Project for this codebase's development. See `docs/agents/issue-tracker.md` for matching Tickets and status workflow.

### Triage labels

The canonical triage roles are native Ticket labels, set through the MCP label tools. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
