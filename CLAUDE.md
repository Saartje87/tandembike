## Agent skills

### Issue tracker

Tickets live in the local Tandembike app through MCP at `http://localhost:4747/api/mcp`; use its `Tandembike` Project for this codebase's development. See `docs/agents/start-run.md` for working one Ticket, and `docs/agents/issue-tracker.md` for the rest of the process.

### Triage labels

The canonical triage roles are native Ticket labels, set through the MCP label tools. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
