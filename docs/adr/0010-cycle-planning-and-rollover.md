# Cycles separate planning from Ticket progress

Cycles are goal-led plans within one Project: multiple may be Prepared, but only one may be Active, and each Ticket belongs to at most one non-archived Cycle at a time. Any non-archived Ticket can be planned, whatever its Status, so a Cycle can also record work that was finished before it was planned. Archiving a planned Ticket keeps it in its Cycle, so restoring it brings it back to the same plan; it can still be unplanned while archived, and archiving the Cycle treats it like any other member, by its Status. Starting a Prepared Cycle while another is Active requires confirmation to archive the current Cycle and rolls its unfinished, non-archived Tickets into the selected Cycle, while its Done Tickets stay behind. Archiving takes a Cycle's unfinished Tickets out of it, back to the Backlog, so an Archived Cycle keeps only the Done Tickets as a record of the work done in it, and those are not part of the Backlog (#69). Cycles archived before #69 may still hold unfinished Tickets; those show in the Backlog. This keeps plans distinct from Ticket Status, allows the next plan to be prepared without conflicting assignments, and makes rollover deliberate while preserving unfinished work.
