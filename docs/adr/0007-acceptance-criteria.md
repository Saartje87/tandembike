# Acceptance criteria are an optional Ticket checklist

Acceptance criteria belong to a Ticket as an optional, ordered checklist of independently verifiable statements, each with its own checked state. Checklist progress is separate from Ticket Status: a Ticket may be Done with unchecked criteria, and completing all criteria does not change its Status. Keep criteria separate from the Markdown description so the User and Agents can manage them consistently; do not automatically migrate existing description content. Show checked/total progress on Board cards only when a Ticket has criteria.
