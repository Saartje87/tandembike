# The User can delete Tickets; Agents only archive

ADR 0003 keeps every removal reversible so that an Agent's mistake is cheap to undo. We keep that for Agents, who still only archive, but let the User delete a Ticket for good from the UI. No MCP tool deletes, so ADR 0003's reason still holds, and the User, who owns the app, can still clear out Tickets that should never have existed. A deleted Ticket is gone everywhere: its labels, Comments, acceptance criteria, Blockers on both sides and Activity (ADR 0009) go with it, and it leaves every Cycle, even an Archived Cycle's history. Its number is never reused. Deleting an Epic detaches its children by default, so a deletion never takes work the User did not name; the User can choose to delete them with it (#62). We rejected deleting only archived Tickets, because the extra archive step adds nothing a confirmation doesn't, and refusing to delete a Ticket that was in an Archived Cycle, because that would cover most finished work.
